# Project Setup

## Objective

Define the minimum, repeatable steps required to prepare a local AImetos development environment.

## Prerequisites

- Git access to this repository.
- Component-specific runtimes only when that component is introduced.
- Local environment values stored outside version control.

## Setup procedure

1. Clone the repository and check out `main`.
2. Copy future `.env.example` files to local `.env` files.
3. Follow the component README or runbook when implementations exist.
