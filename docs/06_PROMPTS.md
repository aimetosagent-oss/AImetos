# Prompt Management

## Objective

Treat production prompts as versioned product behavior with explicit evaluation and ownership.

## Prompt record

Each prompt should document purpose, inputs, outputs, constraints, fallback behavior, model requirements, owner, and version.

## Safety and quality

Do not embed secrets or personal data. Test prompts against representative and adversarial cases before release.
