# Engineering Workflow

## Objective

Provide a simple, reviewable path from an idea to a safe production change.

## Change flow

1. Define scope and acceptance criteria.
2. Update relevant documentation.
3. Implement the smallest useful change.
4. Validate locally and record evidence.
5. Review, merge, deploy, and monitor.

## Git conventions

Use focused commits, descriptive messages, and short-lived branches when collaboration requires them.
