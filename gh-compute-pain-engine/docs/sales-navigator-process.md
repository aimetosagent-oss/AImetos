# Procés Sales Navigator

## Workflow exacte

1. Open a qualified A or B lead in `03_LEADS_CUALIFICADOS`.
2. Search the company in LinkedIn Sales Navigator.
3. Identify a maximum of two decision-makers.
4. Prioritize these roles:
   - Founder
   - Co-Founder
   - Managing Director
   - Design Director
   - Computational Design Lead
   - Digital Design Lead
   - Head of Engineering
   - Engineering Manager
   - Technical Director
   - R&D Manager
   - BIM Manager
   - Digital Fabrication Manager
5. Add name, role, and LinkedIn URL manually to the qualified lead row.
6. Set `lead_status` to `Validated`.
7. Run workflow 03 manually to create a reviewable draft.
8. Review, edit if needed, and send manually.
9. Mark `outreach_status` as `Sent manually` only after real manual sending.
